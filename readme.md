
Информационная безопасность


Собрать MVP системы с реализацией следующих средств защиты:
• RSA – 32768
• Кузя – Кузнечик (ГОСТ)
• Стрибог – 512 (ГОСТ)
• NFA (3FA)
• Форма регистрации (+регулярки)
• Форма восстановления пароля.

Ранги пользователей:
o Гость. Без прав, только просмотр
o Пользователь. Может зайти в систему, ввести сообщение, зашифровать его одним из доступных методов, просмотреть историю своих вводов, сохранить в формате PDF одно из выбранных сообщений.
o Админ. Может включать/выключать методы шифрования доступные пользователю, просматривать сообщения всех пользователей, создавать пользователей.
• Коды восстановления / коды одноразового доступа
• Почтовый сервер для 3FA

Алгоритм:
• Входим в систему, если пользователь имеем возможность шифрования сообщения либо RSA, либо Кузнечик.
• У пользователя должен отображаться список всего того, что он уже зашифровывал и он может каждое сообщение скачать в PDF с исходником и результатом после шифрования. Файл подписывается ЭЦП.
• У администратора видны записи всех пользователей
• В базе данных должно выполняться хэширование паролей
